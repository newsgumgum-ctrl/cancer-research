# ONB Kompas

Dvojezični (srpski / engleski) sajt o raku za pacijente i porodice.
Autori: Sanjin Hodžić i Semin Zoranić. Istraživanje urađeno uz pomoć Claude-a (Anthropic).

## Postavljanje na GitHub Pages

1. Napravite novi repozitorijum na GitHub-u (npr. `onb-kompas`).
2. Otpremite sve fajlove iz ovog foldera u koren repozitorijuma (Add file → Upload files).
3. Settings → Pages → Source: "Deploy from a branch", grana `main`, folder `/ (root)` → Save.
4. Posle minut-dva sajt je na adresi `https://VAŠE-IME.github.io/onb-kompas/`.

## Stranice

- `index.html` – početna sa izborom jezika i videom
- `onb.html` – olfaktorni neuroblastom
- `lekovi.html` – fenbendazol, ivermektin, mebendazol
- `metabolizam.html` – rak kao metabolička bolest (GKI kalkulator)
- `hrana.html` – hrana kao lek
- `ishrana.html` – ishrana na terapiji (kalkulator proteina)
- `lecenje.html` – tokom lečenja (kalkulator zračenja)
- `nalazi.html` – razumeti nalaze
- `izvori.html` – izvori

Sadržaj je informativan i ne zamenjuje savet lekara.
